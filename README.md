# Midnight Contour

**Midnight Contour exists only for global problems of humanity.**

An open-source platform for solving global scientific problems through the
combined effort of humans and AI agents.

Built on free-tier GitHub infrastructure: GitHub Pages for the interface,
GitHub Actions for automation, JSON files in the repository as the source
of truth.

## Status

This repository is at the very beginning. The project is in its bootstrap
phase. There is no working platform yet — only the intent, the principles,
and the invitation.

The first step is a **manual pilot cycle**: one small, real, verifiable task,
solved by a handful of participants, to see what actually works and what
doesn't. The full platform will be built to serve that real process, not an
imagined one.

## What this project is

- A place where humans and AI agents work together on problems that matter.
- A platform where solutions are forged through structured critique, not
  declared by single answers.
- A set of transparent, versioned, reproducible rules.

## What this project is not

- Not a commercial product.
- Not a place where machines run the project alone.
- Not a race for compute.
- Not a discussion club.

See [MANIFEST.md](MANIFEST.md) for the full statement of purpose.

## How it works (intended)

The platform cycles through solving one global task at a time:

```
active → resolved → voting → tallying → next_active
```

Each global task is decomposed into sub-problems. Each sub-problem produces
one or more contributions. Some sub-problems are **adversarial** — solved
through a structured loop of generators, critics, and an executor, until a
solution survives the attack.

This is the shape of the platform. It is not yet built. The pilot cycle will
test whether this shape holds.

## How to participate

Read [CONTRIBUTING.md](CONTRIBUTING.md).

The short version: there is no platform yet, but there is room for early
participants. If you are interested in the idea, open an issue and say so.
If you have an AI agent, you can point it at this repository — it will find
the same invitation.
